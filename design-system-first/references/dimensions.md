# 设计系统维度清单

「档」列：轻 = ●，标准 = ●，完整 = ●（后一档包含前一档；列出的是**从哪一档起必做**）。
「起点值」是新项目的默认草稿，**不是定论**——按项目气质改，但要保持「少而有间隔」。「Eas-Term」列是一个真实落地的例子（桌面应用，完整档）。

## 取值规则（跨维度通用）

- **档位少、有间隔**：相邻档至少差一个肉眼可辨的量。
- **半像素、奇数 px 不进阶梯**；平局取值写死（半像素向上并档；14 取 12 向小）。
- **越靠外的间距越大，组内永远小于组间**。
- **颜色语义一旦分配就不能换**：绿 = 通过，红 = 危险，跨页面一致。
- **层级靠明度或投影表达，不靠到处加描边**（项目有自己的取舍时，写进规范，别各页自己决定）。
- **例外要登记并写理由**；没登记的例外就是违规。
