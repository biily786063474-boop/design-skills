# 推导规则（`scripts/derive.mjs` 实现的就是这些）

锚点 = **气质**（主色、中性色倾向）、**密度**、**形状性格**（同时决定圆角、阴影、动效），加上平台、档位、主题。下面每条规则都在脚本里有校验，不达标会报错，不会静默放行。要改规则，改脚本和单测，再改这份文档。

## 一张表看全

| 维度 | 由什么推出 | 规则 |
| --- | --- | --- |
| 字阶 | 密度、平台 | 基础字号：紧凑 13 / 标准 14 / 舒展 16，触屏平台抬到正文下限（iOS 17、Android 16）。7 档 = 基础 × 步进系数^k，k = −3…+3，取整数 px；步进系数紧凑 1.10 / 标准 1.125 / 舒展 1.15；严格递增，最小字号有下限（紧凑与标准 10，舒展 11，iOS 11，Android 12） |
| 字重、行高 | 密度 | 字重 400 / 500 / 600；行高正文 1.5 / 1.55 / 1.6，标题 1.25 |
| 间距 | 固定 | 阶梯 0 / 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64，2px 栅格 |
| 版式间距 | 密度 | 组内 < 同组条目 < 区块之间；卡片间距 ≤ 区块间距；页边距窄面板 ≤ 弹窗·设置页 ≤ 全幅，全部取自间距阶梯 |
| 控件高度 | 密度、平台 | 紧凑 24 / 28 / 32；标准 28 / 32 / 40；舒展 32 / 40 / 48。触屏平台中档 ≥ 44（iOS）/ 48（Android），小档 −8、大档 +8；视觉比触控下限小的控件要把点击热区扩到下限 |
| 圆角 | 形状 | 基准 r0 = 4 / 8 / 12；6 档 = r0 × 0.5 / 1 / 1.5 / 2 / 3 / 4，取偶数；另有胶囊 9999。嵌套规则：内层 = 外层 − 内边距，下限 4 |
| 颜色色阶 | 主色 | 主色转 OKLCH，色相与彩度保留，亮度换成固定的 11 档阶梯（50…950）；**用户选的主色原样放进离它亮度最近的那一档**；高彩度超出 sRGB 色域时降彩度、不改亮度 |
| 中性色 | 主色、倾向 | follow：色相跟主色、彩度 0.012；none：纯灰 |
| 语义色 | 固定 | 成功 150°、警告 85°、危险 25°、信息 245°，彩度 0.14，亮度与主色阶梯对齐；含义一旦分配不换 |
| 主题映射 | 明暗 | 亮：背景中性 50，卡片白，文字 900 / 700 / 600；暗：背景中性 950，卡片 900，文字 50 / 300 / 400。强调填充：亮色从 500 起依次试 500 / 600 / 700 / 800 / 900，取第一个与白字对比度 ≥ 4.5 的档，暗色从 400 起依次试 400 / 300 / 500 / 600，取第一个与卡片对比度 ≥ 3 的档 |
| 阴影 | 形状、明暗 | 3 档（偏移 1 / 4 / 12，模糊 2 / 12 / 32）；透明度随形状（锐利更重、圆润更轻）；暗色透明度 ×3.5，且主要靠表面明度分层 |
| 动效 | 形状 | 4 档时长：锐利 100 / 160 / 240 / 360ms，适中 120 / 200 / 300 / 450ms，圆润 150 / 240 / 350 / 500ms；缓动 ease-out（进场与反馈）、ease-inOut（位移）；仅「圆润」加弹簧、只给小控件；`prefers-reduced-motion` 全局覆盖 |
| z-index | 固定 | 7 层：base 0 / raised 10 / sticky 20 / dropdown 30 / modal 40 / toast 50 / tooltip 60 |
| 焦点环、状态 | 固定 | 焦点环 2px 实线主色、偏移 2；禁用 0.4、弱化 0.6、悬停叠层 0.06、按下叠层 0.10 |
| 断点 | 平台 | Web 与桌面：640 / 1024 / 1440；原生平台没有，用系统的尺寸类别 |
| 状态矩阵、页面版式、功能区标准 | 以上全部 | 自动生成成表，引用令牌 |

## 校验清单（每次推导都跑）

字号整数、字阶严格递增且不重合、基础字号落在中档、最小字号不低于下限、触屏平台正文不低于下限；控件高度偶数且递增、触屏平台中档不低于触控下限；圆角偶数且递增；版式间距全在阶梯里、组内 < 条目 < 区块、卡片间距 ≤ 区块、页边距递增；z-index 7 层间隔 10；动效时长递增；每个主题的对比度（正文 / 背景 ≥ 7，次要与说明 ≥ 4.5，强调色上的文字 ≥ 4.5，强调填充与焦点环对卡片或背景 ≥ 3，四个语义色 ≥ 4.5）；tokens.json 里的别名都能解析且无循环。

## 已知边界

- **字阶步进系数（1.10 / 1.125 / 1.15）是实测挑出来的**：这三个值在取整后 7 档不会重合。换成别的系数要重跑单测里的全组合扫描。
- **阴影、动效的具体数值是经验值**，没有拿用户实测验证。
- **原生平台只落了约束与令牌**：没有生成 Swift、Kotlin 的令牌文件，需要的话由 `tokens.json` 再转一层。
- **对比度只算了文字与界面元素这两类**，不替代完整的 WCAG 审计（键盘、焦点顺序、读屏、目标间距这些要另查）。
- **不管字体选择**：默认系统字体栈，用户给了字体名才写进 `fonts`。
